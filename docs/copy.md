# iCITY 113Н — тексты

Все тексты сайта, по экранам. Числа — из `docs/facts.md`, ничего сверх него.

**Правила набора.** Разряды — узкий неразрывный пробел `U+202F`: `1 300 000 ₽`.
Десятичная запятая: `244,1 м²`, `3,8 м`. Тире — длинное, с пробелами.
Кавычки — «ёлочки». Микро-лейблы капителью, всё остальное строчными.

**Запрещённые слова.** «Премиальный», «уникальный», «не имеющий аналогов»,
«статусный», «элитный», «инновационный», «пространство мечты». Если хочется
написать прилагательное — напиши вместо него число или название.

```

```

имя PRIDEX для арендатора класса А+ значит больше, чем слово «дизайнерская».

> Если заказчик сочтёт «завтра» обещанием конкретного срока — запасной
> вариант: «Офис, готовый к въезду. Не через полгода.» Ритм слабее,
> смысл тот же.


Формулировку «исключительная особенность высотного проектирования»
из буклета MR Group не цитируем — это их маркетинг, а не наш факт.

стоит ноль и снимает риск целиком, а «приезжайте и сверьте» превращает
оговорку в приглашение.


**Заголовок**


**Таблица**

| | Отделка с нуля | Помещение 113Н |
|---|---|---|
| Проект и согласования | нужны | сделано |
| Ремонт | нужен | сделан |
| Мебель | закупается отдельно | входит |
| Срок до въезда | месяцы | день обращения |
| Капитальные затраты | бюджет отделки | **0 ₽** |
| Риск срыва сроков | есть | нет |

Левая колонка на подложке `--paper-3`. Единственное красное на экране —
`0 ₽`. Строки разделены отступом, а не линейками.

**Строка под таблицей**
```
Всё, что обычно оплачивается до въезда, здесь уже оплачено.
```

**Условия**
```
1 300 000 ₽ в месяц
НДС и эксплуатационные расходы включены
Коммунальные — по счётчикам
Депозит 2 месяца · срок от 11 месяцев
Прямая аренда от собственника
```

Конкретных сумм и сроков ремонта в левой колонке нет намеренно: вилка
стоимости fit-out не подтверждена, а выдуманное число — первое, что
проверит аналитик и на чём потеряет доверие ко всей странице.

## Состояния формы

**Отправляется**
```
Отправляем…
```

**Успех**
```
Готово. Оксана перезвонит на +7 909 ___-__-__.
Если удобнее написать — её мессенджер выше.
```

**Ошибка сети**
```
Не отправилось. Попробуйте ещё раз или позвоните
напрямую: +7 909 379-80-15.
```

**Пустое имя**
```
Как к вам обращаться?
```

**Некорректный телефон**
```
Проверьте номер — кажется, не хватает цифр.
```

Ошибки не обвиняют пользователя и всегда дают обходной путь.
